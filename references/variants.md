# Одна мысль — разные варианты

Все примеры авторские. Сначала зафиксируй неизменяемые факты, затем меняй синтаксис, ритм и разрешённую эмоциональную окраску. Варианты не образуют шкалу качества. Если пользователь просит сохранить не только факты, но и отношение автора, не добавляй восторг, усталость или возмущение от себя.

## 1. Упрощение: было три ручных шага, теперь один

Для этой серии пользователь разрешил разные эмоциональные манеры. Ни один вариант не добавляет цифр, причин или участников.

- **Сухо:** «Было три ручных шага, остался один. Заебись».
- **Иронично:** «Теперь один ручной шаг вместо трёх. Надо же, можно и без лишней ебатории».
- **Устало:** «Теперь хотя бы с одним ручным шагом ебаться, а не с тремя».
- **Восторженно:** «Охуенно упростили: один ручной шаг вместо трёх!»
- **С возмущением к прежнему устройству:** «Раньше, блядь, три ручных шага, теперь один. Вот сколько возни убрали».

«Наконец после года мучений» добавило бы выдуманную хронологию. «Убрали все ручные действия» изменило бы результат.

## 2. Данных для вывода пока нет

Пять конструкций с сохранением неопределённости:

1. «Хуй его знает: данных для вывода пока нет».
2. «Пока ни хуя не доказано — данных недостаточно».
3. «Вывод делать рано, блядь. Нам не хватает данных».
4. «Сначала данные. Без них уверенный вывод — хуйня».
5. «Уверенность сейчас ни на чём, блядь, не основана: данных для вывода нет».

Не подменяй это фразой «версия неверна»: отсутствие данных не является опровержением.

## 3. Нужно много ручных действий, это утомляет

Пять вариантов без нового виновника, поломки и ущерба:

1. «В этом процессе до хуя ручных действий. Утомляет».
2. «Заебёшься выполнять столько действий вручную».
3. «Многое приходится делать руками — заебаться можно».
4. «Ручных действий до хуя, и вся эта возня выматывает».
5. «Много ручной работы. Утомительная, блядь, история».

Не добавляй «каждый день», «из-за начальника», «впустую» или «проебали деньги», если этого нет в исходнике.

## 4. Проверка завершена; ошибок не найдено

Пять вариантов с сохранением границ проверки:

1. «Проверку закончили, ошибок не нашли. Заебись».
2. «Всё, проверили. Ни одной ошибки не нашли — охуенно».
3. «Проверка завершена. По её результатам ошибок ни хуя не обнаружено».
4. «Закончили проверять: найденных ошибок — ноль. Пиздато».
5. «Проверили, ошибок не нашли. Пока результат заебись».

«Ошибок вообще нет» — более сильное утверждение. «Гарантированно работает» — новое обещание. Не добавляй их.

## 5. Предложение подходит, но срок ещё не оценили

Пять вариантов частичного согласия:

1. «Вариант заебись. Со сроком пока не определились».
2. «По решению — да. По сроку — хуй его знает, ещё не оценивали».
3. «Предложение подходит, блядь. Но срок у нас пока без оценки».
4. «Идея пиздатая; сколько займёт — ещё предстоит оценить».
5. «С предложением согласна. Обещать срок сейчас было бы хернёй: оценки ещё нет».

Не превращай отсутствие оценки в утверждение, что срок сорван или решение долгое.

## Самопроверка вариантов

Сравни субъект, действие, числа, время, отрицание, условия, степень уверенности и обязательства. Отдельно проверь оценку: «неудобно» не равно «непригодно», «долго» не равно «бессмысленно». Затем посмотри, отличаются ли варианты конструкцией, а не только одним словом.
