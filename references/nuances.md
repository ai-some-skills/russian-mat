# Оттенки близких слов

Авторские рекомендации для выбора формулировки, опирающиеся на значения словаря. Это не измерение частотности и не жёсткая шкала: интонация, контекст и отношения могут изменить эффект.

[Навигация](lexicon.md) · [Сочетаемость](collocations.md)

| Группа | Различие | Примеры |
|---|---|---|
| хуйня / хуетень / поебень | «Хуйня» — широкая оценка: чушь, мелочь, плохая вещь. «Хуетень» удобно выделяет ненужные детали и возню. «Поебень» добавляет пренебрежение к вещи, нередко надоевшей. Это ориентиры, значения пересекаются. | «Вывод — хуйня: данные ему противоречат». «Убери декоративную хуетень». «Опять чинить эту поебень». |
| заебало / остопиздило / заебался | Первые два — что-то надоело; «остопиздило» может звучать как накопившееся раздражение. «Заебался» — устал сам говорящий. | «Меня заебало ждать». «Ожидание остопиздило». «Я заебался ждать». |
| заебись / охуенно / пиздато | Все могут хвалить. «Заебись» хорошо работает отдельной реакцией, «охуенно» — сильным восторгом или усилением, «пиздато» — оценкой качества. Ни одно не исключает иронию. | «Заебись, получилось». «Охуенно быстро». «Пиздато сделано». |
| хуёво / хуевато / ни в пизду | Плохо / плоховато / непригодно. Последнее категоричнее и требует основания именно для вывода о пригодности. | «Работает хуевато» не равно «ни для чего не годится». |
| охуеть / приохуеть / прихуеть | Сильная реакция / несколько ослабленная в авторском современном употреблении / словарный вариант ослабления. «Приохуеть» здесь современный пример, не статья антологии. | «Охуеть от цены». «Немного прихуел от цены». Реакция не доказывает, что цена объективно завышена. |
| наебать / ошибиться / напиздеть | Обмануть / допустить ошибку / наврать или наболтать. Ошибка не доказывает намеренный обман. | «В отчёте ошибка» нельзя без данных переписать как «нас наебали». |
| пиздеть / попиздеть / пиздёж | Болтать или лгать / поговорить либо приврать / разговоры или ложь. Значение определяется контекстом. | «Давай попиздим» обычно не приглашение врать. |
| доебаться / приебаться / уточнить | У «доебаться» есть оттенок дотошного выяснения и значение приставания. «Приебаться» акцентирует придирку. «Уточнить» оставляет действие нейтральным. | «Доебусь до условия» можно сказать о своей тщательности. «Он приебался» уже оценка чужого поведения. |
| проебать / проебаться | Растратить, проиграть или, в современных примерах, упустить / провозиться без толку, а также современное «ошибиться». Возвратность меняет конструкцию. | «Проебал срок». «Проебался с оценкой срока». Не всякое долгое занятие — потерянное время. |
| въёбывать / хуярить / ебаться | Интенсивно работать / энергично делать с разными возможными значениями / возиться, часто утомительно. «Ебаться» не обязательно означает прогресс, «въёбывать» не гарантирует результат. | «Въёбывали всю ночь». «Хуярит заготовки». «Ебётся с настройкой». |
| пиздец / пиздарики / охуеть | Первые два могут обозначать конец и провал; «пиздец» также усиливает восторг. «Охуеть» обычно выражает реакцию, не само событие. | «Срокам пиздец» — оценка положения; «я охуел от сроков» — реакция говорящего. |
| подъёбка / критика / оскорбление | Подкол / разбор конкретных недостатков / унижение адресата. Мат может быть в любом из трёх, но не делает их одинаковыми. | «Три согласования для галочки — мощно» может быть подъёбкой. Объяснение ненужности трёх шагов — критика. |

## Как выбирать

Сначала определи, что утверждается: факт, оценка качества, усталость, реакция, намерение другого человека или характеристика адресата. Затем выбирай слово. Замена, которая меняет этот тип утверждения, требует пересмотра смысла.

Не вставляй редкий синоним только ради разнообразия. «Коноёбица» может подойти для нарочитой стилизации, но в коротком объяснении «заебался возиться» понятнее.
